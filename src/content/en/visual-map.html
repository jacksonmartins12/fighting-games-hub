Visual Map: How Everything Connects

Understanding fighting games is not about learning isolated concepts. It's understanding how they interconnect. This visual map shows the dependency structure and relationships between all major concepts you've learned.

The Learning Hierarchy

How Concepts Build On Each Other

Foundation Layer (Month 1): Attack-Block-Throw triangle, basic movement, understanding the screen. Without this, nothing else makes sense.

Intermediate Layer (Months 2-3): Frame data literacy, anti-air timing, combo confirmation. These require foundation but unlock footsies.

Advanced Layer (Months 4-6): Footsies mastery, meter management, okizeme setups. These require everything below them.

Master Layer (Month 7+): Adaptation, character matchups, psychological reads. This is where intuition and experience compound.

Concept Dependency Map

  • Execution Excellence → enables all other skills (you can't implement strategies without executing them)
    • Combos require execution
    • Okizeme setups require execution
    • Footsies require micro-execution (precise buttons/directions)
  • Footsies Mastery → foundation of all strategy
    • Range control → meter building → okizeme advantage
    • Spacing → anti-air positioning → cleaner conversions
    • Baiting → reads → mixup defense
  • Frame Data Understanding → enables matchup knowledge
    • Know your buttons → space correctly → win footsies
    • Know opponent buttons → predict patterns → read them
    • Know unsafe gaps → punish them → control matches
  • Meter Management → separates matches
    • Spend wisely → more security/damage when needed
    • Build strategically → have meter when opponent panics
    • Force usage → track their Drive Gauge and punish them when they are in Burnout
  • Psychology & Adaptation → ties everything together
    • Apply consistent pressure → opponent deviates from optimal play
    • Read their patterns → exploit them
    • Adjust strategy between rounds and games → win the set

Cross-Disciplinary Improvements

One powerful principle: Improving in one area often improves others automatically.

Better Footsies

→ Cleaner combos (easier conversions)

→ More meter (Drive Gauge from landing pokes, less wasted on panic moves)

→ Better okizeme setups (superior space control)

Better Execution

→ Cleaner footsies (can buffer more)

→ Better okizeme (precisely timed meaty setups)

→ More combo damage (tighter combos)

Better Psychology

→ Better reads (understand opponent)

→ Better meter usage (know when pressure works)

→ Better adaptation (react to patterns)

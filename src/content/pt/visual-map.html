Mapa Visual: Como Tudo se Conecta

Entender jogos de luta não é aprender conceitos isolados. É entender como eles se interligam. Este mapa visual mostra a estrutura de dependências e as relações entre todos os conceitos principais que você aprendeu.

A Hierarquia de Aprendizado

Como os Conceitos se Apoiam Uns nos Outros

Camada de Base (Mês 1): Triângulo Ataque-Defesa-Agarrão, movimentação básica, entender a tela. Sem isso, nada mais faz sentido.

Camada Intermediária (Meses 2-3): Saber ler frame data, timing de anti-air, hit-confirm de combos. Exigem a base, mas destravam o footsies.

Camada Avançada (Meses 4-6): Domínio de footsies, gestão das barras, setups de okizeme. Exigem tudo o que vem abaixo.

Camada de Mestre (Mês 7+): Adaptação, matchups de personagens, leituras psicológicas. É aqui que intuição e experiência se acumulam.

Mapa de Dependência de Conceitos

  • Excelência de Execução → habilita todas as outras habilidades (você não aplica estratégia que não consegue executar)
    • Combos exigem execução
    • Setups de okizeme exigem execução
    • Footsies exige microexecução (botões/direções precisos)
  • Domínio de Footsies → base de toda estratégia
    • Controle de distância → ganho de barra → vantagem no okizeme
    • Espaçamento → posicionamento para anti-air → conversões mais limpas
    • Bait → leituras → defesa contra mixups
  • Entendimento de Frame Data → habilita o conhecimento de matchups
    • Conheça seus botões → use o espaçamento certo → vença o footsies
    • Conheça os botões do oponente → preveja padrões → leia o oponente
    • Conheça as brechas inseguras → puna → controle as partidas
  • Gestão das Barras → decide partidas
    • Gaste com sabedoria → mais segurança/dano quando precisar
    • Acumule com estratégia → tenha barra quando o oponente entrar em pânico
    • Force o gasto → acompanhe a Drive Gauge dele e puna quando ele estiver em Burnout
  • Psicologia e Adaptação → amarra tudo
    • Pressione com consistência → o oponente se desvia do jogo ideal
    • Leia os padrões dele → explore-os
    • Ajuste a estratégia entre rounds e partidas → vença o set

No Que Focar em Cada Fase

Meses 1-2 Execução + Fundamentos Básico de frame data Assistir a partidas de pros

Meses 4-6 Footsies (Elementos 4-35) Setups de okizeme Psicologia

Melhorias que Atravessam Áreas

Um princípio poderoso: Melhorar em uma área muitas vezes melhora as outras automaticamente.

Footsies Melhor

→ Combos mais limpos (conversões mais fáceis)

→ Mais barra (Drive Gauge ganha ao acertar pokes e menos desperdiçada em golpes de desespero)

→ Setups de okizeme melhores (controle de espaço superior)

Execução Melhor

→ Footsies mais limpo (dá para fazer mais buffer)

→ Okizeme melhor (setups de meaty com timing preciso)

→ Mais dano nos combos (combos mais otimizados)

Psicologia Melhor

→ Leituras melhores (entender o oponente)

→ Uso melhor das barras (saber quando a pressão funciona)

→ Adaptação melhor (reagir aos padrões)
